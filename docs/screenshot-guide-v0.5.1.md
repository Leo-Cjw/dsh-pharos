2. **关闭 macOS 专注/勿扰模式**（系统设置 → 专注模式）。开着的话通知横幅会被系统吞掉，
   `screenshot-1` 拍不到横幅（这是 2026-10-02 踩过的坑）
3. 表单里的字段需要**手动填**——DSH 的 webview 收不到键盘输入事件，AI 代填不了。
   建议先手动填好一份有代表性的配置，再拍

## 处理管线

拍完放回 `assets/`，然后跑处理脚本（修 macOS 窗口阴影的 alpha → cover 缩放 → 居中裁切到
1600×900 → 写入 `assets/`）：

```bash
python3 .workbuddy/shots/prepare-shot.py <输入图> <输出名> [--size WxH] [--no-trim] [--dry-run]
```

`--dry-run` 先看裁切结果，满意了再去掉。先备份旧图（`git checkout assets/` 可回退，
所以直接覆盖也行——旧图已入库，随时能取回）。

## 拍完怎么走

图放进 `assets/` 后告诉我，我做剩下的事：

1. 校验 5 个文件名与 `screenshots.json` 声明一致（必须是 ASCII、不得以 `/` 开头或含 `..`）
2. 跑 `npm pack --dry-run` 确认图入包、体积可接受
3. 复跑 `node test/smoke.mjs` + `node test/host.test.mjs`
4. 同步安装副本、校验两端 md5
5. 提交 → 打 `v0.5.1` tag → 推 `origin/main` + tag
6. 把 awesome-dsh-plugin 的 PR #6353 更新到最新提交

注意：**本轮只推 Git，不发 npm**（本机未登录 npm，且 dsh-pharos 在 npmjs/npmmirror 上
都还没有这个包；历史版本也只有 git tag）。市场侧的版本更新走 git 源。
